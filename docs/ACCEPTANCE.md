# 主要功能验收矩阵

上海如静知华信息科技有限公司 · https://www.zhuatech.cn/

## 验收目标

承运商 → 运价审批 → 运单发运/妥投 → 账单核验 → 差异贷项或更正 → 应付审批 → 付款核销

| 模块 | 已实现功能 | 可执行操作 |
|---|---|---|
| 承运商 | 承运商联系与结算资料 | 新建、编辑、查询、详情、导出 |
| 运输价卡 | 按线路、生效日期与重量计算运费 | 审批生效 |
| 运输运单 | 计费重量与妥投凭证 | 确认发运、登记妥投 |
| 承运商账单 | 自动计算应付、超差争议与调整 | 运价核验、登记承运商贷项、审批应付、核销付款、更正账单重审 |
| 运费付款流水 | 已审批账单付款与价卡快照 | 业务动作自动生成、查询、追溯、导出 |

## 界面验收

检查业务端模块列表、新建与详情、服务端错误反馈，以及管理端账号权限和审计入口；桌面截图及管理端截图见 README。所有演示金额和人员均为虚构。

## 不宣称已覆盖的事项

一期为单币种、按计费重量和固定线路报价的整单运费审核；不含体积重自动测量、多段路由、关税/燃油指数在线抓取与银行付款。

不将本机测试当成真实生产负载的压力测试，也不声称通过安全合规认证、故障切换或客户现场验收。测试事实见 [测试结果](TEST-RESULTS.md)。

## 增补安全与并发回归

四个不同请求同时修改同一版本，只允许一个成功；五次密码错误后暂时锁定；另一企业的 HTTP 会话无法读到单据、审计或附件；同一秒创建的记录使用数据库顺序号确定先后。
